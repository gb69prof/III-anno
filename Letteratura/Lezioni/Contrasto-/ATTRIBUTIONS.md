## Ricostruzioni visuali

Le otto scene in `assets/scenes/` sono state generate con IA appositamente per questa PWA e dirette secondo `docs/VISUAL_BIBLE.md`. Non sono fonti primarie né fotografie di un evento storico. Ogni immagine è accompagnata nell’interfaccia da:

1. base documentaria o testuale;
2. scelta visuale dichiarata;
3. riferimenti;
4. alt text descrittivo.

Il melograno, la soglia, la loggia, l’aspetto del piccolo codice e il pubblico sullo sfondo sono scelte ricostruttive, non dettagli attestati dal testo.

## Software

PWA in HTML, CSS e JavaScript senza dipendenze esterne. Le icone sono originali e incluse nel progetto.
