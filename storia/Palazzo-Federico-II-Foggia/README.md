# Il palatium di Federico II a Foggia

PWA storico-scientifica destinata a un pubblico generico, attento e colto. Il percorso mostra che cosa possiamo sapere del palatium federiciano, attraverso quali prove e dove comincia l'ipotesi.

## Funzioni

- otto capitoli in modalità Racconto;
- archivio Prove con ricerca e filtri A-E;
- epigrafe di fondazione interattiva;
- mappa schematica della corte mobile;
- timeline regressiva della scomparsa;
- laboratorio argomentativo con salvataggio locale;
- bibliografia scientifica;
- tema chiaro/scuro, responsive, accessibilità e funzionamento offline.

## Avvio locale

Servire la cartella con un web server statico, per esempio:

```bash
python3 -m http.server 8080
```

Il service worker richiede `http://localhost` o HTTPS.

## Principio metodologico

La PWA distingue cinque gradi di attendibilità: A prova primaria diretta, B forte consenso scientifico, C ricostruzione plausibile, D ipotesi discussa, E tradizione non dimostrata. Ogni scheda chiarisce anche ciò che la fonte non attesta.
